## 📌 Описание

`VVER_1200_Sim_Server` — серверная подсистема реального времени, выполняющая численное интегрирование системы дифференциальных уравнений нейтронной физики и термогидравлики энергоблока ВВЭР-1200 (проект АЭС-2006).

Сервер транслирует широковещательный поток телеметрии (20 кадров в секунду) по протоколу WebSocket и принимает управляющие воздействия от клиентских приложений (React-панель экзаменатора, Unity 3D БЩУ, системы аналитики).

## 🔬 Физико-математическая модель

1. **Точечная кинетика нейтронов (6 групп ДН)**:
   - Учет запаздывающих нейтронов с временами жизни и выходами $\beta_i, \lambda_i$;
   - Остаточное энерговыделение после останова (модель стандарта ANS-5.1);
   - Расчет периода разгона реактора $T_{\text{пер}}$ и реактивности в pcm ($10^{-5} \Delta k/k$).
2. **Обратные связи по реактивности**:
   - Допплер-эффект топлива: мгновенная температурная обратная связь топлива ($\alpha_{\text{fuel}} < 0$);
   - Температурный эффект замедлителя/теплоносителя ($\alpha_{\text{cool}} < 0$);
   - Борное регулирование: учет концентрации борной кислоты ($C_{\text{boron}}$, ppm).
3. **Термогидравлика 1-го контура (4 петли)**:
   - Активная зона: температуры оболочек ТВЭЛ, топлива и теплоносителя ($T_{\text{in}} \approx 298.2^\circ\text{C}$, $T_{\text{out}} \approx 328.9^\circ\text{C}$);
   - 4 петли с главными циркуляционными насосами ГЦН-1391;
   - Компенсатор давления (КД): ТЭН мощностью $2.52$ МВт, система впрыска из холодной нитки, баланс пара/воды.
4. **Второй контур и паротурбинная установка**:
   - 4 горизонтальных парогенератора ПГВ-1000МКП (пар $7.0$ МПа, $285.8^\circ\text{C}$);
   - Паропроводы свежего пара и питательная вода;
   - Турбогенератор $1200$ МВт эл., регулирующие клапаны, стопорные клапаны (СК ТП);
   - Быстродействующие редукционные установки БРУ-К (сброс пара в конденсатор) и БРУ-А (в атмосферу).
5. **Автоматика защит и светосигнальное табло БЩУ**:
   - Аварийная защита **АЗ-1** (сброс стержней СУЗ со скоростью $1.2$ м/с при превышении уставок);
   - Предупредительная защита **ПЗ-1**;
   - Формирование битовой маски сигнализаций для табло БЩУ.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск сервера симуляции
```bash
npm start
```
Сервер стартует на порту `3000` (настраивается переменной `PORT` в `.env`).

После запуска доступны:
- 🌐 **Встроенный диагностический пульт**: [`http://localhost:3000/`](http://localhost:3000/)
- 📡 **WebSocket стриминг**: `ws://localhost:3000` (20 Гц)
- 📊 **REST API**: [`http://localhost:3000/api/status`](http://localhost:3000/api/status)

## 🛠 Скрипты и инструменты CLI

В `package.json` настроены удобные команды для разработки и валидации физики:

| Команда | Назначение |
|---|---|
| `npm start` | Запуск сервера реального времени (WebSocket + HTTP + физический цикл 20 Гц) |
| `npm run simulation:test` | Запуск автоматических валидационных тестов физической модели (проверка стационара, сброса нагрузки, отключения ГЦН, АЗ-1) |
| `npm run simulation:demo` | Консольная демонстрация переходных процессов в терминале |
| `npm run simulation:export` | Расчет и экспорт динамики параметров в файл `simulation_output.csv` |
| `npm run build` | Компиляция TypeScript в чистый JavaScript (`dist/`) |

## 🧪 Валидация физической модели

Для запуска набора валидационных тестов:
```bash
npm run simulation:test
```
Тестовый раннер проверяет:
1. Выход на стационарный номинальный режим 100% $N_{\text{ном}}$ ($3200$ МВт тепл. / $1200$ МВт эл.);
2. Поведение при самопроизвольном отключении ГЦН-2 (температурный перекос, снижение мощности);
3. Динамику расхолаживания и спада мощности после срабатывания АЗ-1 (ANS-5.1);
4. Удержание давления первым контуром при переходных процессах.
