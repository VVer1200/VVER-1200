--------------------------------------------------------------------------------
1) ДАТЧИКИ СИСТЕМ И ИНДИКАТОРЫ (СВЕТОСИГНАЛЬНЫЕ ТАБЛО И ЛАМПЫ БЩУ ДЛЯ UNITY)
--------------------------------------------------------------------------------
Передаются в объекте телеметрии "lamps" в виде булевых флагов (true/false).
true = лампа/табло горит (активно), false = погашено.

1.1. КРАСНЫЕ ТАБЛО (Аварийные защиты, аварии оборудования, опасные уставки):
--------------------------------------------------------------------------------
* lamps.LAMP_AZ1            [bool] - Срабатывание Аварийной Защиты 1-го рода (АЗ-1, сброс стержней СУЗ)
* lamps.LAMP_AZ2            [bool] - Срабатывание Аварийной Защиты 2-го рода (АЗ-2)
* lamps.LAMP_PZ1            [bool] - Срабатывание Предупредительной Защиты (ПЗ-1)
* lamps.LAMP_CRIT_POWER     [bool] - Аварийная мощность реактора (> 107% / > 3424 МВт)
* lamps.LAMP_CRIT_PERIOD    [bool] - Аварийно малый период разгона реактора (0 < T_per < 10 с)
* lamps.LAMP_P_PRIM_HIGH_TRIP [bool] - Аварийно высокое давление 1 контура (> 17.6 МПа)
* lamps.LAMP_P_PRIM_LOW_TRIP  [bool] - Аварийно низкое давление 1 контура (< 14.5 МПа)
* lamps.LAMP_T_OUT_HIGH_TRIP  [bool] - Аварийная температура на выходе из реактора (> 335.0 °C)
* lamps.LAMP_SG_LEVEL_LOW_TRIP [bool] - Аварийно низкий уровень в парогенераторе (< 1.8 м)
* lamps.LAMP_TURBINE_TRIPPED  [bool] - Аварийный останов турбины (стопорные клапаны ТСК посажены)
* lamps.LAMP_GRID_DISCONNECT  [bool] - Генератор отключен от энергосистемы (разрыв связи с ЛЭП)

1.2. ЖЕЛТЫЕ ТАБЛО (Предупредительные сигнализации, отклонения параметров):
--------------------------------------------------------------------------------
* lamps.LAMP_POWER_WARN     [bool] - Предупреждение: высокая мощность реактора (> 104% / > 3328 МВт)
* lamps.LAMP_PERIOD_WARN    [bool] - Предупреждение: короткий период разгона (0 < T_per < 20 с)
* lamps.LAMP_P_PRIM_WARN    [bool] - Давление 1 контура выше нормы (> 16.6 МПа)
* lamps.LAMP_P_SEC_WARN     [bool] - Давление свежего пара выше нормы (> 7.5 МПа)
* lamps.LAMP_SG_LEVEL_HIGH  [bool] - Высокий уровень воды в парогенераторе (> 2.6 м)
* lamps.LAMP_RCP1_OFF       [bool] - Отключен ГЦН-1 (петля №1)
* lamps.LAMP_RCP2_OFF       [bool] - Отключен ГЦН-2 (петля №2)
* lamps.LAMP_RCP3_OFF       [bool] - Отключен ГЦН-3 (петля №3)
* lamps.LAMP_RCP4_OFF       [bool] - Отключен ГЦН-4 (петля №4)
* lamps.LAMP_BRU_K_OPEN     [bool] - БРУ-К открыт (сброс пара в конденсатор турбины)
* lamps.LAMP_BRU_A_OPEN     [bool] - БРУ-А открыт (сброс пара в атмосферу)
* lamps.LAMP_PZR_HEATERS_FULL [bool] - Включены все группы ТЭН компенсатора давления (100% мощности)
* lamps.LAMP_PZR_SPRAY_ON   [bool] - Работает впрыск холодной воды в компенсатор давления
* lamps.LAMP_BORON_INJECTION [bool] - Идет ввод концентрированной борной кислоты (ввод отриц. реактивности)
* lamps.LAMP_PURE_WATER     [bool] - Идет ввод чистой обессоленной воды (дилюция, ввод полож. реактивности)

1.3. ЗЕЛЕНЫЕ И СИНИЕ ИНДИКАТОРЫ (Штатное состояние агрегатов и автоматики):
--------------------------------------------------------------------------------
* lamps.LAMP_STEADY_STATE   [bool] - Энергоблок находится в стабильном стационарном режиме
* lamps.LAMP_GRID_SYNC      [bool] - Генератор синхронизирован с энергосетью (50 Гц)
* lamps.LAMP_ROD_TOP        [bool] - Рабочая группа СУЗ на верхнем концевике (извлечена на 100%)
* lamps.LAMP_ROD_BOTTOM     [bool] - Рабочая группа СУЗ на нижнем концевике (погружена на 0%)
* lamps.LAMP_AUTO_PRESSURE  [bool] - Включен автоматический регулятор давления 1 контура (16.20 МПа)
* lamps.LAMP_AUTO_LEVEL_SG  [bool] - Включен автоматический регулятор уровня в ПГ (2.40 м)


--------------------------------------------------------------------------------
2) ЗНАЧЕНИЯ ПАРАМЕТРОВ (АНАЛОГОВЫЕ ТЕХНОЛОГИЧЕСКИЕ ДАТЧИКИ И ТЕРМОГИДРАВЛИКА)
--------------------------------------------------------------------------------
Передаются в корневом объекте JSON телеметрии:

2.1. Реактор, нейтроника и тепловыделение:
* powerMW             [МВт]     (ном. 3200.0) - Полная тепловая мощность реактора (Q_thermal)
* powerPct            [%]       (ном. 100.0)  - Тепловая мощность в процентах от номинала
* qFissMW             [МВт]     (ном. 3008.0) - Мощность мгновенного деления урана
* fuelTempC           [°C]      (ном. 600.0)  - Средняя температура уранового топлива (UO2)
* periodSec           [с]       (ном. inf)    - Период удвоения мощности реактора
* boronPpm            [ppm]     (ном. 550.0)  - Концентрация борной кислоты в теплоносителе
* reactivityTotalPcm  [pcm]     (ном. 0.0)    - Суммарная реактивность ядра (1 pcm = 10^-5 dk/k)
* reactivityDopplerPcm [pcm]    (ном. 0.0)    - Доплеровская обратная связь по топливу
* reactivityCoolantPcm [pcm]    (ном. 0.0)    - Температурная обратная связь по теплоносителю
* reactivityRodsPcm   [pcm]     (ном. 0.0)    - Реактивность от стержней СУЗ
* reactivityBoronPcm  [pcm]     (ном. 0.0)    - Реактивность от концентрации бора

2.2. Первый контур (реактор, петли, компенсатор давления):
* pPrimMPa            [МПа]     (ном. 16.20)  - Давление теплоносителя первого контура
* coreInTempC         [°C]      (ном. 298.2)  - Температура на входе в реактор (холодные нитки)
* coreOutTempC        [°C]      (ном. 328.6)  - Температура на выходе из зоны (горячие нитки)
* deltaTC             [°C]      (ном. 30.4)   - Подогрев теплоносителя в реакторе (Tout - Tin)
* tCoolAvgC           [°C]      (ном. 313.4)  - Средняя температура теплоносителя в активной зоне
* flowPrimKgS         [кг/с]    (ном. 17600.0)- Суммарный массовый расход через активную зону
* levelPzrM           [м]       (ном. 7.85)   - Уровень теплоносителя в компенсаторе давления
* pzrHeaterPowerMW    [МВт]     (ном. 0.45)   - Текущая мощность ТЭН компенсатора давления
* pzrHeaterGroups     [шт]      (ном. 1)      - Количество включенных групп ТЭН (0..4)
* pzrSprayFlowKgS     [кг/с]    (ном. 0.0)    - Расход впрыска холодной воды в КД

2.3. Главные циркуляционные насосы (4 петли):
* rcpStates           [массив]  ([T, T, T, T])- Состояние 4 насосов: [ГЦН-1, ГЦН-2, ГЦН-3, ГЦН-4]
* rcpCountActive      [шт]      (ном. 4)      - Число работающих насосов (0..4)
* rcpSpeed            [отн.ед]  (ном. 1.0)    - Относительная скорость вращения ротора ГЦН

2.4. Второй контур и парогенераторы:
* pSecMPa             [МПа]     (ном. 7.00)   - Давление свежего пара во 2 контуре (в коллекторе ПГ)
* steamFlowKgS        [кг/с]    (ном. 1773.25)- Паропроизводительность парогенераторов
* levelSgM            [м]       (ном. 2.40)   - Весовой уровень воды в парогенераторах
* turbFlowKgS         [кг/с]    (ном. 1773.25)- Расход пара на паровую турбину
* bruKFlowKgS         [кг/с]    (ном. 0.0)    - Расход сброса пара через БРУ-К в конденсатор
* bruAFlowKgS         [кг/с]    (ном. 0.0)    - Расход сброса пара через БРУ-А в атмосферу

2.5. Турбоагрегат и электрический генератор:
* electricMW          [МВт]     (ном. 1185.7) - Электрическая мощность генератора нетто
* turbMechMW          [МВт]     (ном. 1209.9) - Механическая мощность на валу турбины
* turbRpm             [об/мин]  (ном. 3000.0) - Частота вращения вала ротора турбогенератора
* freqHz              [Гц]      (ном. 50.0)   - Частота переменного тока в энергосистеме
* turbineStopValvesOpen [bool]  (ном. true)   - Стопорные клапаны турбины (true=открыты, false=посажены)
* gridBreakerClosed   [bool]    (ном. true)   - Выключатель генератора (связь с энергосистемой)

2.6. Фактическое состояние органов управления:
* rodPosActual        [отн.ед]  (ном. 0.70)   - Фактическое положение группы СУЗ (0.00..1.00)
* valveActual         [отн.ед]  (ном. 1.00)   - Фактическое открытие клапанов турбины
* pzrControlMode      [string]  ("AUTO")      - Режим регулятора давления 1 контура ("AUTO" / "MANUAL")
* fwControlMode       [string]  ("AUTO")      - Режим регулятора питательной воды ("AUTO" / "MANUAL")
* boronPumpRunning    [bool]    (false)       - Состояние насоса борной кислоты
* pureWaterPumpRunning [bool]   (false)       - Состояние насоса чистой воды
* scramActive         [bool]    (false)       - Факт сброса аварийной защиты АЗ-1


--------------------------------------------------------------------------------
3) УПРАВЛЕНИЕ (КОМАНДЫ ОТ UNITY / ПУЛЬТА ОПЕРАТОРА НА СЕРВЕР)
--------------------------------------------------------------------------------
Команды отправляются клиентом в сокет в виде JSON-строки:
ws.send(JSON.stringify({ type: "ИМЯ_КОМАНДЫ", ... }));

* type: "SET_RODS"
  Поля:   value [number: 0.0 .. 1.0]
  Смысл:  Перемещение рабочей группы стержней СУЗ (0.0 = упор внизу, 1.0 = извлечены на 100%)

* type: "TRIP_AZ"
  Поля:   нет
  Смысл:  Кнопка АЗ-1 (Аварийная защита) - немедленный гравитационный сброс всех стержней

* type: "TOGGLE_RCP"
  Поля:   index [number: 0..3], value [boolean]
  Смысл:  Пуск / Останов выбранного ГЦН (index: 0=ГЦН-1, 1=ГЦН-2, 2=ГЦН-3, 3=ГЦН-4)

* type: "SET_RCP_SPEED"
  Поля:   value [number: 0.2 .. 1.0]
  Смысл:  Регулирование скорости вращения работающих ГЦН

* type: "SET_PZR_MODE"
  Поля:   value [string: "AUTO" или "MANUAL"]
  Смысл:  Переключение регулятора давления КД (автомат держит 16.20 МПа)

* type: "SET_PZR_HEATERS"
  Поля:   value [number: 0.0 .. 2.52] (МВт)
  Смысл:  Ручное включение ТЭН компенсатора давления (для режима MANUAL)

* type: "SET_PZR_SPRAY"
  Поля:   value [number: 0.0 .. 1.0]
  Смысл:  Ручное открытие впрыска в компенсатор давления (для режима MANUAL)

* type: "SET_FW_MODE"
  Поля:   value [string: "AUTO" или "MANUAL"]
  Смысл:  Переключение регулятора питательной воды (автомат держит уровень 2.40 м)

* type: "SET_FW_FLOW"
  Поля:   value [number: 0.0 .. 2400.0] (кг/с)
  Смысл:  Ручное задание расхода питательной воды (для режима MANUAL)

* type: "SET_TURBINE_VALVE"
  Поля:   value [number: 0.0 .. 1.1]
  Смысл:  Положение регулирующих клапанов турбины

* type: "TRIP_TURBINE"
  Поля:   value [boolean: true = открыть СК, false = аварийный срыв вакуума/сброс ТСК]
  Смысл:  Аварийная посадка главных стопорных клапанов турбоагрегата

* type: "TOGGLE_GRID"
  Поля:   value [boolean: true = включен в сеть, false = отключен]
  Смысл:  Подключение/отключение генератора от энергосистемы 50 Гц

* type: "SET_BORON_PUMP"
  Поля:   value [boolean: true / false]
  Смысл:  Включение/выключение насоса концентрированной борной кислоты

* type: "SET_PURE_WATER_PUMP"
  Поля:   value [boolean: true / false]
  Смысл:  Включение/выключение насоса чистой обессоленной воды (дилюция)

* type: "SET_BORON_RATE"
  Поля:   value [number: -2.0 .. +2.0] (ppm/с)
  Смысл:  Скорость ввода бора или чистой воды

* type: "SET_BRU_K"
  Поля:   value [number: 0.0 .. 1.0 или -1 для автомата]
  Смысл:  Положение быстродействующей редукционной установки со сбросом в конденсатор

* type: "SET_BRU_A"
  Поля:   value [number: 0.0 .. 1.0 или -1 для автомата]
  Смысл:  Положение редукционной установки со сбросом пара в атмосферу

* type: "RESET"
  Поля:   нет
  Смысл:  Мгновенный сброс всей физической модели в номинальное стационарное состояние 100% мощности
