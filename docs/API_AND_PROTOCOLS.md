# Спецификация сетевых протоколов и API симулятора ВВЭР-1200

> **Документ**: Сетевой протокол и справочник команд  
> **Версия протокола**: v1.1  
> **Транспорт**: WebSocket (Real-Time 20 Гц) + HTTP REST  

---

## 1. Точки подключения (Endpoints)

| Протокол | URL | Описание |
|---|---|---|
| **WebSocket** | `ws://localhost:3000` | Двусторонний полнодуплексный канал: прием телеметрии (20 Гц) и отправка команд в реальном времени. |
| **HTTP GET** | `http://localhost:3000/api/status` | Опрос текущего состояния сервера, статуса стационарности и настроек органов управления. |
| **HTTP POST** | `http://localhost:3000/api/command` | Отправка команд управления в формате JSON (альтернатива отправке через WebSocket). |
| **HTTP GET** | `http://localhost:3000/` | Встроенный тестовый веб-пульт (`TEST_DASHBOARD.html`) для экспресс-диагностики сервера. |

---

## 2. Формат телеметрии (WebSocket Broadcast, 20 Гц)

Каждые $50$ миллисекунд сервер рассылает всем подключенным клиентам JSON-сообщение типа `TELEMETRY`:

### Описание полей телеметрии:

| Поле | Тип | Ед. изм. | Описание |
|---|---|---|---|
| `time` | `number` | с | Виртуальное время симуляции |
| `powerMW` | `number` | МВт | Тепловая мощность реактора (номинал 3200 МВт) |
| `powerPct` | `number` | % | Процент от номинальной тепловой мощности |
| `fuelTempC` | `number` | °C | Средняя температура топлива в активной зоне |
| `periodSec` | `number` | с | Период разгона реактора (аварийный при < 10 с) |
| `boronPpm` | `number` | ppm | Концентрация борной кислоты в теплоносителе |
| `reactivityTotalPcm` | `number` | pcm | Полная реактивность (1 pcm = $10^{-5} \Delta k/k$) |
| `p1MPa` | `number` | МПа | Давление первого контура (номинал 16.2 МПа) |
| `tInC` / `tOutC` | `number` | °C | Температура теплоносителя на входе/выходе реактора |
| `loopFlowKgS` | `number[]`| кг/с | Расход теплоносителя по 4 петлям (4 элемента) |
| `rcpActive` | `boolean[]`| флаги | Статус работы главных циркуляционных насосов (ГЦН 1..4) |
| `pzrLevelM` | `number` | м | Уровень теплоносителя в компенсаторе давления |
| `pzrHeaterPowerMW`| `number` | МВт | Текущая мощность ТЭН компенсатора давления |
| `p2MPa` | `number` | МПа | Давление пара во втором контуре (номинал 7.0 МПа) |
| `sgLevelsM` | `number[]`| м | Уровни котловой воды в 4 парогенераторах |
| `turbinePowerMW`| `number` | МВт | Электрическая мощность турбогенератора (номинал 1200 МВт) |
| `turbineRpm` | `number` | об/мин | Частота вращения валопровода турбины (номинал 3000) |
| `azTripped` | `boolean` | флаг | Сработала ли аварийная защита АЗ-1 |
| `annunciators` | `object` | флаги | Карта состояний светосигнальных ламп БЩУ |

## 3. Словарь команд управления

Команды отправляются клиентом в виде JSON-объекта через WebSocket-соединение `ws.send(JSON.stringify(cmd))` или через HTTP POST `/api/command`.

### 3.1. Ввод внештатных воздействий инструктора
```json
{
  "action": "INJECT_FAULT",
  "fault": "RCP2_TRIP"
}
```
Поддерживаемые сценарии (`fault`):
- `RCP2_TRIP` / `Отключение ГЦН-2` — останов ГЦН петли №2 с динамическим перекосом температур и падением расхода.
- `PRESSURE_SURGE` / `Рост давления первого контура` — перевод ТЭН КД на максимум и блокировка впрыска.
- `SG_LEVEL_DROP` / `Снижение уровня в ПГ` — аварийное уменьшение расхода питательной воды до 400 кг/с.
- `GRID_LOSS` / `Отключение генератора от сети` — сброс электрической нагрузки, разгон ротора, срабатывание БРУ-К.
- `AZ_TRIP` / `Аварийная защита` — ручной сброс стержней СУЗ по кнопке АЗ-1.

### 3.2. Управление стержнями СУЗ и химводоочисткой
- `SET_ROD_TARGET`: положение регулирующей группы от `0.0` (полностью опущены) до `1.0` (полностью извлечены).
  ```json
  { "action": "SET_ROD_TARGET", "value": 0.85 }
  ```
- `SET_ROD_MODE`: `AUTO` или `MANUAL`.
- `SET_BORON_PUMP`: включение насоса ввода бора `true` / `false`.
- `SET_PURE_WATER_PUMP`: включение насоса дистиллята `true` / `false`.
- `TRIP_AZ`: непосредственный ручной срыв стержней АЗ-1.

### 3.3. Главные циркуляционные насосы (ГЦН 1..4)
- `TOGGLE_RCP`: включение/отключение конкретного насоса (индекс `0`..`3`).
  ```json
  { "action": "TOGGLE_RCP", "index": 1, "value": false }
  ```
- `SET_RCP_SPEED`: относительная частота вращения (от `0.2` до `1.0`).

### 3.4. Компенсатор давления и парогенераторы
- `SET_PZR_MODE`: режим давления (`AUTO` / `MANUAL`).
- `SET_PZR_HEATERS`: мощность нагревателей КД в МВт (от `0.0` до `2.52`).
- `SET_PZR_SPRAY`: степень открытия клапана впрыска (от `0.0` до `1.0`).
- `SET_FW_MODE`: режим питательной воды ПГ (`AUTO` / `MANUAL`).
- `SET_FW_FLOW`: суммарный расход питательной воды в кг/с (`0.0` .. `2400.0`).

### 3.5. Турбина, генератор и сброс блока
- `SET_TURBINE_VALVE`: открытие клапанов турбины (`0.0` .. `1.1`).
- `TRIP_TURBINE`: посадка стопорных клапанов турбины `false` (трип турбины) или открытие `true`.
- `TOGGLE_GRID`: синхронизация генератора с энергосистемой `true` / `false`.
- `RESET`: мгновенный возврат всего энергоблока в стационарный номинал 100% мощности.
  ```json
  { "action": "RESET" }
  ```
