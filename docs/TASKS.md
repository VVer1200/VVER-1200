> **Статус доски:** Активно  

---

## 🎯 Правила выполнения следующего изменения

Каждое новое изменение в проекте выполняется строго по циклу:  
**Задача в бэклоге (Issue) $\to$ Тематическая ветка $\to$ Изменение и локальные тесты $\to$ Pull Request $\to$ Проверка CI $\to$ Ревью коллеги $\to$ Слияние в `main`**.

### Чек-лист готовности изменения (Definition of Done для PR):
- [ ] Изменение решает конкретную задачу из списка ниже;
- [ ] Внесены необходимые unit/валидационные тесты;
- [ ] Команда `npm run simulation:test` возвращает 16 `[PASS]` без регрессий;
- [ ] Сборка `npm run build` проходит без ошибок на клиенте и сервере;
- [ ] Получено одобрение (Approve) минимум от одного другого участника команды.
