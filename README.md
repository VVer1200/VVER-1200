## 📖 Обзор репозитория

Данный репозиторий содержит клиентскую интерфейсную часть учебно-тренировочного комплекса **ВВЭР-1200** — веб-приложение `power-unit-operator-simulator`.

Интерфейс спроектирован с учетом требований эргономики АСУ ТП блочных щитов управления (БЩУ) современных атомных станций поколения 3+ и решает следующие задачи:
- **Отображение состояния энергоблока**: вывод параметров реактора, первого и второго контуров, турбогенератора и электросетей с частотой обновления 20 Гц.
- **Интерактивная мнемосхема (Plant Mimic)**: визуализация циркуляции теплоносителя, положения стержней СУЗ, работы ГЦН, уровня в компенсаторе давления и парогенераторах.
- **Табло сигнализаций БЩУ (Annunciators)**: матрица ламп световой аварийной (АЗ-1) и предупредительной (ПЗ-1) сигнализации.
- **Пульт инструктора/экзаменатора**: запуск учебных тренировок, ввод внештатных ситуаций (отключение ГЦН, броски давления, течи, сброс нагрузки) в один клик.
- **Протокол сессии (Event Logger)**: фиксация всех воздействий оператора и системы с экспортом в отчет.

## ✨ Основные возможности

| Модуль | Назначение и функциональность |
|---|---|
| **Мнемосхема энергоблока** | Высокодетализированная векторная схема реакторного отделения и машзала с анимированными потоками, положением регулирующей группы СУЗ и вращением ротора турбины. |
| **Панель телеметрии** | Карточки цифровых приборов (Nном, Tтопл, Tвх/вых, P1, P2, Nэл, fсети) с цветовой индикацией безопасных диапазонов. |
| **Светосигнальное табло** | Полнофункциональный аналог световых табло панелей БЩУ: АЗ-1, ПЗ-1, высокое/низкое давление, срыв генератора. |
| **Консоль внештатных ситуаций** | Ввод регламентных аварий: «Отключение ГЦН-2», «Рост давления 1 контура», «Падение уровня ПГ», «Отключение генератора», «Сброс АЗ-1». |
| **Журнал событий** | Таймлайн с категоризацией (Инструктор, Оператор, Система, Авария) и фильтрацией в реальном времени. |

## 🚀 Быстрый старт

### Требования:
- **Node.js** `18+` или `20+`
- Запущенный сервер математической модели `VVER_1200_Sim_Server` (на порту `3000`)

### Установка и запуск:

```bash
# 1. Перейдите в директорию веб-приложения
cd power-unit-operator-simulator

# 2. Создайте файл конфигурации окружения (при необходимости настройте URL)
cp .env.example .env

# 3. Установите зависимости
npm install

# 4. Запустите dev-сервер
npm start
```

Интерфейс запустится по адресу: **`http://localhost:3001`**.

## 🔌 Интеграция с сервером симуляции

Приложение взаимодействует с сервером физики по протоколам WebSocket и HTTP REST:
- **WebSocket URL**: `ws://localhost:3000` (частота телеметрии: 20 Гц / 50 мс);
- **HTTP API**: `http://localhost:3000/api/status` и `/api/command`.

Переменные окружения задаются в файле `.env`:
```env
PORT=3001
REACT_APP_SIM_WS_URL=ws://localhost:3000
REACT_APP_SIM_HTTP_URL=http://localhost:3000
```
