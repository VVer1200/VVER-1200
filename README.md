## 📖 Обзор репозитория

Данный репозиторий содержит полный учебно-тренировочный комплекс **ВВЭР-1200**:
1. **`VVER_1200_Sim_Server`** — сервер физико-математической модели реального времени на TypeScript (численное интегрирование ОДУ кинетики и термогидравлики с шагом 50 мс, WebSocket-стриминг 20 Гц).
2. **`power-unit-operator-simulator`** — клиентская веб-панель оператора и инструктора БЩУ на React (интерактивная мнемосхема, табло сигнализаций, пульт ввода аварий).

## ✨ Основные возможности

| Модуль | Назначение и функциональность |
|---|---|
| **Мнемосхема энергоблока** | Высокодетализированная векторная схема реакторного отделения и машзала с анимированными потоками, положением регулирующей группы СУЗ и вращением ротора турбины. |
| **Панель телеметрии** | Карточки цифровых приборов (Nном, Tтопл, Tвх/вых, P1, P2, Nэл, fсети) с цветовой индикацией безопасных диапазонов. |
| **Светосигнальное табло** | Полнофункциональный аналог световых табло панелей БЩУ: АЗ-1, ПЗ-1, высокое/низкое давление, срыв генератора. |
| **Консоль внештатных ситуаций** | Ввод регламентных аварий: «Отключение ГЦН-2», «Рост давления 1 контура», «Падение уровня ПГ», «Отключение генератора», «Сброс АЗ-1». |
| **Журнал событий** | Таймлайн с категоризацией (Инструктор, Оператор, Система, Авария) и фильтрацией в реальном времени. |

## 🚀 Быстрый старт (Запуск из чистого клона)

Для полноценной работы комплекса необходимо запустить сервер симуляции и клиентскую часть:

### Терминал 1: Сервер физической симуляции (`VVER_1200_Sim_Server`)
```bash
# 1. Перейдите в директорию сервера
cd VVER_1200_Sim_Server

# 2. Установите зависимости
npm install

# 3. Запустите автоматическую проверку физики (16 тестов)
npm run simulation:test

# 4. Запустите сервер симуляции (порт 3000)
npm start
```
*Эндпоинт проверки статуса сервера:* [`http://localhost:3000/api/status`](http://localhost:3000/api/status)  
*Диагностический веб-пульт:* [`http://localhost:3000`](http://localhost:3000)

### Терминал 2: Клиентская панель оператора/инструктора (`power-unit-operator-simulator`)
```bash
# 1. Перейдите в директорию веб-клиента
cd power-unit-operator-simulator

# 2. Создайте файл окружения (по умолчанию ws://localhost:3000)
cp .env.example .env

# 3. Установите зависимости
npm install

# 4. Запустите dev-сервер интерфейса (порт 3001)
npm start
```
Интерфейс откроется по адресу: **`http://localhost:3001`**. Индикатор в шапке покажет: `● СЕТЬ: ОНЛАЙН (20 Гц)`.

## 🔌 Интеграция с сервером симуляции

Приложение взаимодействует с сервером физики по протоколам WebSocket и HTTP REST:
- **WebSocket URL**: `ws://localhost:3000` (частота телеметрии: 20 Гц / 50 мс);
- **HTTP API**: `http://localhost:3000/api/status` и `/api/command`.

Переменные окружения задаются в файле `.env`:
```env
PORT=3001
REACT_APP_SIM_WS_URL=ws://localhost:3000
REACT_APP_SIM_HTTP_URL=http://localhost:3000
```
