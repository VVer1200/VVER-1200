# power-unit-operator-simulator

Учебный React-интерфейс инструктора для проекта «Тренажер оператора энергоблока» на основе ВВЭР-1200.

## Что реализовано
- единая панель инструктора без авторизации на текущем этапе;
- текущие показатели энергоблока;
- мониторинг активной тренировки;
- планирование и запуск тренировки или экзамена;
- выбор оператора, сценария и сложности;
- создание внештатных событий;
- журнал действий оператора, инструктора и системы;
- результаты и библиотека сценариев;
- компонентная структура React с отдельными CSS-файлами.

## Запуск
```bash
npm install
npm start
```

Сейчас данные демонстрационные. Позже телеметрия может быть заменена реальными данными WebSocket от симулятора ВВЭР-1200.
