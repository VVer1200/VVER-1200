## 📌 Описание

Данное SPA-приложение на React представляет собой рабочее место инструктора-экзаменатора учебного центра АЭС. Интерфейс обеспечивает полный контроль над симуляцией энергоблока ВВЭР-1200, наглядное представление теплофизических параметров, ввод аварийных ситуаций и контроль действий стажера.

---

## ⚡ Что реализовано

- **Интерактивная мнемосхема энергоблока (`PlantMimic`)**:
  - Графическое отображение 1 и 2 контуров в едином технологическом пространстве;
  - Динамическая отрисовка уровня теплоносителя в компенсаторе давления (КД) и парогенераторах (ПГ);
  - Анимация погружения стержней регулирующей группы СУЗ;
  - Статусы 4 петель ГЦН (вращение / отключение / перекос расхода);
  - Анимация турбоагрегата и индикатор выдачи мощности в сеть.
- **Табло аварийной и предупредительной сигнализации БЩУ**:
  - Центральные транспаранты: `АЗ-1` (сброс аварийной защиты) и `ПЗ-1` (предупредительная защита);
  - Сигнализаторы первого контура: давление, температура, уровни, ГЦН;
  - Сигнализаторы второго контура: давление пара, питательная вода, турбина.
- **Консоль экзаменатора (ввод внештатных воздействий)**:
  - «Отключение ГЦН-2»;
  - «Рост давления 1 контура»;
  - «Снижение уровня в ПГ»;
  - «Отключение генератора от сети»;
  - «Ручной сброс АЗ-1»;
  - «Нормализация блока (100% Nном)».
- **Телеметрия 20 Гц**: непрерывный прием и отображение параметров физической модели без лагов и задержек.
- **Журнал учебной сессии**: фиксация действий оператора, инструктора и автоматики защит.
- **Планирование тренировок**: выбор сложности, оператора и сценария.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения
Скопируйте шаблон `.env.example` в `.env`:
```bash
cp .env.example .env
```

### 3. Запуск в режиме разработки
```bash
npm start
```
Приложение запустится на порту `3001` (или другом, указанном в `.env`) и автоматически откроется в браузере: `http://localhost:3001`.

### 4. Сборка для production
```bash
npm run build
```
Готовая статическая сборка будет сформирована в директории `build/`.

## ⚙️ Переменные окружения

| Переменная | Значение по умолчанию | Описание |
|---|---|---|
| `PORT` | `3001` | Порт локального веб-сервера разработки |
| `REACT_APP_SIM_WS_URL` | `ws://localhost:3000` | Адрес WebSocket-сервера симуляции (телеметрия 20 Гц) |
| `REACT_APP_SIM_HTTP_URL` | `http://localhost:3000` | Базовый URL для REST API сервера математической модели |

## 🎨 Компонент мнемосхемы (`PlantMimic`)

Компонент `PlantMimic.jsx` использует векторный SVG с CSS-анимациями:
- Высота стержней СУЗ пропорциональна значению `rodPos` ($0.0 \dots 1.0$);
- Уровень жидкости в КД рассчитывается динамически по полю `pzrLevelM`;
- Индикаторы 4 насосов ГЦН меняют цвет (`зеленый` — норма, `красный` — отключен) и частоту анимации вращения;
- Подсветка линий циркуляции отражает градиент температур (горячая нитка $328.9^\circ\text{C}$ / холодная нитка $298.2^\circ\text{C}$).

## 🔄 Сетевое взаимодействие (`simulatorService.js`)

Служба `simulatorService` инкапсулирует:
- Автоматическое подключение и реконнект (Exponential Backoff) при разрыве связи;
- Троттлинг обновлений состояния для снижения нагрузки на React Fiber;
- Очередь команд управления и отправку через активный WebSocket-сокет или fallback на HTTP POST `/api/command`.
